# Viscraft

India-based visa and travel services business, serving Indian customers. This repo holds the project knowledge base and working documents for the [Framer](https://framer.com) website build — the site itself has no code export (deliberate), so this repo is docs, wireframes, and assets, not the site's source.

## Working with this repo

Two people are working on this project in parallel, each via Claude CLI. Pull/fetch before starting a session — pushes from either side land on the shared remote with no automatic sync. Prefer working on a branch and merging deliberately rather than committing straight to `main`, same discipline as the Framer project itself (which is version-controlled separately, via Framer's own project-level branching — not through this repo).

Wireframes live in `/wireframes` (add as they're ready).
